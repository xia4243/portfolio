イチゴ熟度検出システム

アップロードした画像から、イチゴの果実を検出し熟度を 4 段階で自動判定する Web アプリケーション。卒業研究の YOLOv8 モデルを、誰でも使える Web サービスへと実装しました。

Overview

研究成果を、
「使えるプロダクト」へ。

学習済みの物体検出モデルは、そのままでは専門家しか扱えません。本プロジェクトでは、画像をアップロードするだけで誰でも熟度判定ができる Web UI を設計し、結果の可視化・PDF レポート出力・履歴管理までを実装しました。

Challenge

取り組んだ課題

01

専門知識なしで使える UI

ドラッグ&ドロップで画像を投げるだけ。検出結果をその場で可視化。

02

重い AI 処理の分離

推論を独立サービス化し、Web 側の応答性を確保。

03

多言語・マルチデバイス

日中英の 3 言語対応とレスポンシブで、幅広い利用者に。

Architecture

システム構成3-TIER ARCHITECTURE

Frontend

Vue 3 + Vite

Element Plus / Pinia / vue-router / vue-i18n。画面・状態管理・多言語・ダークモード・PWA。

Backend

Spring Boot 3

Java 17 / Spring Security + JWT 認証 / JPA。履歴管理・PDF 出力・レート制限・管理 API。

AI Service

FastAPI + YOLOv8

Python / Ultralytics / OpenCV。画像から果実を検出し熟度を推論する独立サービス。

Front-end Highlights

フロントエンドの工夫

「動く」だけでなく、実務水準の使い勝手・保守性を意識して実装しました。

多言語 i18n

日本語・中国語・英語の 3 言語を全画面で切り替え。21 の名前空間を整理。

ダークモード

設定を永続化し、システム設定にも追従。目にやさしい配色を両モードで設計。

レスポンシブ + PWA

モバイル最適化とインストール対応。出先のスマホでも検出可能。

結果の可視化

Canvas に検出枠を描画。クラス別の絞り込み・集計をその場で表示。

PDF / 共有

検出レポートの PDF 出力・共有リンク・注釈画像ダウンロードに対応。

パフォーマンス計測

独自の計測フックで主要操作の所要時間を可視化し、改善に活用。
